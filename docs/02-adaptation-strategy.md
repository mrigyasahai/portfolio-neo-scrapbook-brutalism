# Phase 3 — Adapting the Design Language into a Portfolio

**Goal: keep the physical "notebook collage" language. Rebuild the purpose, structure, and voice for a portfolio.**

The reference is a **persuasion funnel** (problem → reframe → offer → tracks → apply). A portfolio is **evidence + person** (who am I → what I've done → how I think → how to reach me). Same costume, different skeleton.

---

## 1. Concept: "A Working Notebook of Product Thinking"

The site is presented as the person's **field notebook** — pages torn from a notebook where each section is a spread. This fits the scrapbook language natively and gives a portfolio a narrative spine without copying the reference's landing-page funnel.

Signature moves adapted from the reference:
- **Highlighter-block-behind-text** → highlights the *most important claim* per section (e.g., "I solve product problems").
- **Hard sticker cards** → every case study / principle / stat is a paper cut-out.
- **Monospace "receipt" micro-labels** → hard-fact outcome metrics (e.g., `TAT −63%`, `ROI 3.2×`), a nod to the reference's `Capital: ₹0` texture but repurposed for credibility.
- **Dashed path + numbered circles** → becomes a *timeline path* through the work with numbered stops (2021 → 2026).
- **Marquee** → becomes a skills/discipline ticker (Product · AI · Docs · Shopify …).
- **Rotated callouts** → become margin notes written "in the margins" of case studies (the *voice* color blue).

## 2. What the Reference Gives Us vs. What We Change

| Reference element | Portfolio adaptation |
|---|---|
| "Apply for cohort" CTA | "Let's talk" / email CTA (contact) |
| Program offer + tracks | Case studies (problem → move → outcome) |
| "Four things we hold true" principles | "How I work" principles (4 cards) |
| Roadmap week-by-week table | Writing/Docs samples matrix + toolkit stack |
| Free-flight stat tile (the one that breaks grid) | Featured case study tile |
| Numbers 18→22 journey circles | Work timeline path (numbered stops) |
| Speech-bubble asides | Margin notes on case studies |
| "Exam system" provocation | "Recruiters read portfolios in 90 seconds — so here's the evidence first" (meta, honest) |

## 3. Voice & Copy Direction

- Blunt, declarative, first-person. Short claims.
- Headline system keeps "serious claim + human suffix" two-tone idea (bold wordmark + script accent) without copying "DHANDHA school." The name is the wordmark; a script accent tags the role ("that's me").
- Outcome-first: every case study leads with the number/move, not the activity.

## 4. Design Decisions That Differentiate (not a copy)

1. **Evidence-first hero** — a one-line claim, a proof strip of 3 hard metrics, and a large contact CTA. Recruiters get the answer in 5 seconds.
2. **Case studies as the core artifact** — each is a card with: outcome metric (monospace receipt), problem line, the "move" (what I built), and a margin note. No generic project grid.
3. **Two content speeds** — dense, strictly-gridded *factual* content (case studies, metrics, stack) vs. rotated, chaotic *narrative* elements (margin notes, doodles, timeline). Mirrors the reference's chaos-vs-order rule.
4. **Personal signature: "ink + margin" color semantics** — yellow = the answer, blue = the aside, orange = the numbers, pastels = chapters.
5. **Section "spread" pages** — each section is a full-bleed pastel/paper band framed like a notebook spread, with a tab-style section label (e.g., `WORK / 01`) instead of the reference's marketing eyebrows.

## 5. What the Final Site Will NOT Be

- Not a SaaS landing page (no product demo, no pricing).
- Not a résumé (no chronological job dump as the primary content).
- Not an agency site (no "we do X for Y").
- Not a template portfolio (no generic bento, no grid-of-screenshots).
- Not Apple-minimalism and not glassmorphism (hard edges, hard shadows, warm paper, no blur).
